## 1. Summary of Test Cases

| # | Test Scenario | HTTP Method | Endpoint | Query / Body | Expected Status | Validation / Success Criteria |
|---|---|---|---|---|:---:|---|
| **S1** | Get all books (defaults) | `GET` | `/books` | None | `200 OK` | Returns default 10 books, order_by `id`, order `ASC`, status `"success"`. |
| **S2** | Search by title | `GET` | `/books` | `?search_q=Clean` | `200 OK` | Only returns books with "Clean" in title (`LIKE %Clean%`). |
| **S3** | Sort by price descending | `GET` | `/books` | `?order_by=price&order=DESC` | `200 OK` | Books returned ordered from highest to lowest price. |
| **S4** | Price range filter | `GET` | `/books` | `?min_price=30&max_price=50` | `200 OK` | All returned books satisfy `30 <= price <= 50`. |
| **S5** | Custom pagination | `GET` | `/books` | `?limit=2&offset=2` | `200 OK` | Exactly 2 records returned starting from index offset 2. |
| **S6** | Create new book | `POST` | `/books` | JSON Body (valid title, author, price) | `201 Created` | Book created with autogenerated ID; message returned. |
| **S7** | Get book by ID | `GET` | `/books/:id` | Valid ID (e.g. `1`) | `200 OK` | Returns target book object. |
| **S8** | Update book by ID | `PUT` | `/books/:id` | JSON Body with updated fields | `200 OK` | Updated book record returned with changes persisted. |
| **S9** | Delete book by ID | `DELETE` | `/books/:id` | Valid ID | `200 OK` | Record deleted from SQLite, success message returned. |
| **F1** | Missing title in POST | `POST` | `/books` | Body missing `title` | `400 Bad Request` | `{ "message": "Validation error: 'title' is required..." }` |
| **F2** | Missing author in POST | `POST` | `/books` | Body missing `author` | `400 Bad Request` | `{ "message": "Validation error: 'author' is required..." }` |
| **F3** | Non-numeric price in POST | `POST` | `/books` | `price: "free"` | `400 Bad Request` | `{ "message": "Validation error: 'price' is required and must be a non-negative number" }` |
| **F4** | Inverted price range | `GET` | `/books` | `?min_price=100&max_price=50` | `400 Bad Request` | `{ "message": "Validation error: 'min_price' cannot be greater than 'max_price'" }` |
| **F5** | Get non-existent book | `GET` | `/books/999999` | Non-existent ID | `404 Not Found` | `{ "message": "Book with id 999999 not found" }` |
| **F6** | Update non-existent book | `PUT` | `/books/999999` | Non-existent ID | `404 Not Found` | `{ "message": "Book with id 999999 not found" }` |
| **F7** | Delete non-existent book | `DELETE` | `/books/999999` | Non-existent ID | `404 Not Found` | `{ "message": "Book with id 999999 not found" }` |
| **F8** | Undefined route | `GET` | `/invalid-route` | N/A | `404 Not Found` | Consistent error `{ "message": "Route GET /invalid-route not found" }` |

## 2. Detailed Request & Response Examples

### S1: GET All Books with Defaults
- **Method**: `GET`
- **URL**: `http://localhost:3000/books`
- **cURL**:
  ```bash
  curl -X GET "http://localhost:3000/books"
  ```
- **Response** (`200 OK`):
  ```json
  {
    "status": "success",
    "total": 8,
    "count": 8,
    "limit": 10,
    "offset": 0,
    "order_by": "id",
    "order": "ASC",
    "data": [
      {
        "id": 1,
        "title": "Clean Code",
        "author": "Robert C. Martin",
        "price": 34.99
      }
    ]
  }
  ```

---

### S4: Price Range Filtering
- **Method**: `GET`
- **URL**: `http://localhost:3000/books?min_price=30&max_price=50`
- **cURL**:
  ```bash
  curl -X GET "http://localhost:3000/books?min_price=30&max_price=50"
  ```

  ```json
  {

    "total": 5,
    "count": 5,
    "data": [
      { "id": 1, "title": "Clean Code", "author": "Robert C. Martin", "price": 34.99 },
      { "id": 2, "title": "The Pragmatic Programmer", "author": "Andrew Hunt & David Thomas", "price": 42.5 }
    ]
  }
  ```

---

### S6: Create Book (201 Created)
- **Method**: `POST`
- **URL**: `http://localhost:3000/books`
- **Headers**: `Content-Type: application/json`
- **Body**:
  ```json
  {
    "title": "Designing Data-Intensive Applications",
    "author": "Martin Kleppmann",
    "price": 45.50
  }
  ```
- **cURL**:
  ```bash
  curl -X POST "http://localhost:3000/books" \
    -H "Content-Type: application/json" \
    -d '{"title": "Designing Data-Intensive Applications", "author": "Martin Kleppmann", "price": 45.50}'
  ```
- **Response** (`201 Created`):
  ```json
  {
    "message": "Book created successfully",
    "data": {
      "id": 9,
      "title": "Designing Data-Intensive Applications",
      "author": "Martin Kleppmann",
      "price": 45.5
    }
  }
  ```
